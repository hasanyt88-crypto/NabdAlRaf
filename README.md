# نبض الرف — Nabd Al-Raf (HETARY pro2 · v2.0.0)

## بناء APK
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كما هي.
2. افتح تبويب Actions ثم Build APK ثم Run workflow (أو يعمل تلقائياً عند أي Push).
3. بعد انتهاء البناء نزّل الملف NabdAlRaf-APK من أسفل صفحة التشغيل وثبّته على الجوال.

## قبل البناء
- ضع رابط تدفق Power Automate داخل الثابت `API_URL` في `www/index.html` (أو أدخله من تبويب الإعداد).
- لتغيير الأيقونة استبدل الصور داخل مجلد `assets` بنفس الأسماء.
- للتحديث: عدّل `www/index.html` ثم Push.
